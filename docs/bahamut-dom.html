動畫瘋頁面結構調查（M0）

調查日期：2026-10-23・方式：以未登入狀態抓取伺服器端 HTML。網站改版後需重新驗證，對應程式碼在 apps/extension/src/bahamut/。

重點：可行性評估中擔心的「卡片只帶單集 sn」問題，大部分情況不存在。卡片上的收藏按鈕 animefun.toggleGather(acgSn, animeSn, …) 直接帶有動畫 sn；只有「週期表」的純文字連結需要從同一頁的其他卡片取得對應。

1. 三種 ID

ID意義出現位置
animeSn動畫（作品）。本專案以此為 anime_source.external_idanimeRef.php?sn=、data-animesn、toggleGather 第 2 個參數
videoSn單集animeVideo.php?sn=、data-ani-video-sn
acgSn巴哈 ACG 資料庫作品 IDacgDetail.php?s=、toggleGather 第 1 個參數

animeRef.php?sn=X 會 301 轉址到該動畫第一集的 animeVideo.php，所以「動畫頁」實際上就是播放頁。同一個 animeSn 可能包含多季（例如第 1–13 集是第一季，第 14 集之後是第二季）。

2. 卡片

頁面選擇器連結取得 animeSn名稱
首頁「本季新番」a.anime-card-blockvideoSn最近的 .newanime-date-area[data-animesn]，或卡片內的 toggleGather.anime-name
首頁「週期表」a.text-anime-infovideoSn從同一頁其他卡片建立 videoSn → animeSn 的對應.text-anime-name
首頁熱播／主題推薦、所有動畫a.theme-list-mainanimeSn連結本身.theme-name

圖片採 lazyload：真正的網址放在 img[data-src]。

3. 播放頁 animeVideo.php?sn=

資料來源
videoSn網址的 sn；inline script 中的 animefun.videoSn = 51805;
animeSn、acgSn.anime_name button[onclick*=toggleGather]
動畫名稱.data-file img.data-img 的 alt（h1 會帶「[16]」集數，不適合）
封面.data-file img.data-img 的 data-src，格式為 p2.bahamut.com.tw/B/ACG/c/<acgSn 末兩碼>/<acgSn 補零至 10 碼>.JPG
分類標籤.data-file .tag-list .tag
集數列表section.season li a[data-ani-video-sn]；目前這一集是 li.playing
相關動畫#relanime a.theme-list-main（section.old_list，標題「相關動畫」），卡片結構與首頁相同：href 的 animeRef.php?sn=、.theme-name、img.theme-img 的 data-src。伺服器端 HTML 就有，續作與前一季會互相列出。extension 以 DOM 解析（src/bahamut/parse.ts），server 補抓時以字串解析（apps/server/src/relations.ts）
播放器<video> 由 JS 動態建立，伺服器端 HTML 裡沒有，要用 MutationObserver 等它出現

4. 其他

  • 封面圖片不檢查 Referer，server 可以直接下載。
  • animeRef.php?sn=<animeSn> 會轉到第一集的播放頁，不需登入即可讀取，server 用來補抓相關動畫。

5. 觀看紀錄 API（需登入）

調查日期：2026-10-24。viewList.php 的內容是由 GET https://api.gamer.com.tw/anime/v3/history.php?page=N 載入的，extension 直接讀這個 API（對應程式碼在 src/bahamut/history.ts）。

欄位說明
data.totalPage總頁數；每頁 30 部動畫
data.history[]每部動畫一筆，依最近觀看時間由新到舊
animeSn、videoSn動畫，與最近看的那一集（數字）
title、cover名稱、封面網址
duration最近那一集的片長（分鐘）
watchTime「2026-10-24 10:24:58」格式，台灣時間、無時區，為開始觀看的時間
breakPoint{ breakPoint, watchTime }：最近那一集的進度秒數，-1 表示看完；watchTime 是最後回報進度的時間。沒有進度時可能是空陣列
history[]各集 { videoSn, title, watchTime }，新到舊；title 結尾的「[16]」是集數。每集只有一筆，重看會覆蓋成新的時間
未登入HTTP 200，內容為 {"error":{"code":401,"status":"NO_LOGIN"}}

舊版：解析頁面 DOM（已不使用）
