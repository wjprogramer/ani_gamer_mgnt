Netflix 支援調查

調查日期：2026-10-26・方式：在登入狀態下檢查頁面 DOM、網路請求與播放頁（使用者播放一集後）。網站改版後需重新驗證。對應程式碼在 apps/extension/src/netflix/。

結論：已實作。觀影動態頁本身只有日期，但每部作品的 metadata API 帶有各集的 bookmark（最後觀看時間精確到毫秒、播放位置），所以同步回來的紀錄也能有時間與進度。範圍是 Netflix 上的所有影集與電影；與動畫瘋的同一部作品不自動合併，由管理頁的「合併」頁處理。

1. ID

ID意義出現位置
作品 ID影集或電影，對應 anime_source.external_id卡片連結 /browse?jbv=<id>、/title/<id>
影片 ID單集（電影則與作品相同），對應 episode.external_id觀影動態的 /title/<id>、播放頁 /watch/<id>

觀影動態只給單集的影片 ID，不給作品 ID；要知道屬於哪部作品，需另外查詢（見第 5 節）。

2. 卡片（首頁、類別頁）

資料來源
卡片a[data-uia="standard-card"]、排行榜 a[data-uia="ranked-card"]
作品 ID連結的 jbv 參數
名稱連結的 aria-label
圖片卡片內 img，網址在 *.nflxso.net

class 名稱是編譯產生的雜湊值（例如 default-ltr-…-cache-16qxjbe），不能當選擇器；data-uia 比較穩定。列表是虛擬捲動，捲動時會重建節點，要用 MutationObserver 持續處理。

3. 觀影動態 /viewingactivity

資料來源
每一列li.retableRow[data-uia="activity-row"]，由新到舊
日期.col.date，格式為「YY/M/D」，沒有時間（格式可能隨帳號語系不同）
名稱與影片 ID.col.title a：連結 /title/<影片 ID>；文字為「作品：第 N 季：集名」，電影只有名稱
更多紀錄「顯示更多」按鈕，每次多載入 50 筆
APIPOST /api/aui/pathEvaluator/web/^2.0.0?method=call&callPath=["aui","viewingActivity",頁,筆數]（falcor）。需要帶頁面上的授權參數
其他有「全部下載」可匯出 CSV（同樣只有名稱與日期）；每個設定檔的紀錄分開

觀察到的 70 筆中，同一集沒有重複出現；播放中的那一集只出現一次且在最上面，推測與動畫瘋一樣每集只留最近一次，重看會覆蓋。

4. 播放頁 /watch/<影片 ID>

資料來源
影片 ID網址；自動播下一集時網址會變，但不重新載入頁面
播放器頁面上只有一個 <video>，currentTime、duration 可直接用
標題區[data-uia="video-title"]：h4 是作品名，接著是「第 N 集：」與集名
作品資料用 metadata API 查（見下節），不讀頁面 JS 的變數（content script 讀不到）

5. metadata API

GET https://www.netflix.com/nq/website/memberapi/release/metadata?movieid=<影片 ID>，只需要登入 cookie。傳入單集 ID 也會回傳整部作品。

欄位說明
video.id、type、title作品 ID、show 或 movie、名稱
video.boxart[]直式封面 { w, h, url }（例如 426×607）；卡片上的圖是橫式縮圖，不拿來當封面
video.seasons[].episodes[]id、seq（集數）、runtime（秒）、creditsOffset／watchedToEndOffset（片尾位置）、bookmark
bookmark{ offset, watchedDate }：播放位置（秒）與最後觀看時間（毫秒）；沒看過的集數 watchedDate 為 0
電影沒有 seasons，runtime、bookmark 在 video 上

實測：觀影動態的前 20 筆查了 8 次 metadata，得到 8 部作品、70 集有觀看紀錄（比頁面上載入的更多），其中 19 筆的日期與觀影動態一致。

6. 實作方式

功能做法
卡片與動畫瘋共用卡片程式（隱藏按鈕、標章），以 source 區分
播放時記錄播放頁查 metadata 建檔，沿用 trackWatch
同步開啟觀影動態頁時：依名稱分組，每部作品查一次 metadata（間隔 1 秒），把有 bookmark 的集數匯入；按「再次同步」會包含「顯示更多」後的紀錄
開始時間Netflix 只記最後觀看時間，以「watchedDate − offset」推算；暫停過的話會比實際晚
重複判斷改為比對觀看時段（開始～最後回報）是否重疊，兩個來源共用（見可行性評估 M6）
集數名稱多季：「第 2 季第 43 集」；單季：「43」；電影：「電影」
API 路徑與動畫瘋共用，改為 /api/<source>/...（bahamut、netflix）

限制：Netflix 的評論面板尚未加到頁面上，評論請在管理頁撰寫；背景定時同步未做（觀影動態 API 需要授權參數）。
