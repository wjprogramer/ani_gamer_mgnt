使用與開發說明

需求：Node.js 22.13 以上（使用內建的 node:sqlite）、Chrome。

1. 第一次安裝

npm install
npm run build          # 建置管理頁與 extension
  1. 開啟 chrome://extensions，打開右上角「開發人員模式」。
  2. 按「載入未封裝項目」，選擇 apps/extension/.output/chrome-mv3。

2. 日常使用

npm start              # 啟動本機 server：http://127.0.0.1:17890
  • 隱藏：滑鼠移到動畫瘋的動畫卡片上，左上角會出現「隱藏」。隱藏後預設摺疊成一行，可按「還原」。
  • 觀看紀錄：在播放頁開始播放就會自動記錄，之後每 15 秒回報一次進度；進度達片長 85% 視為看完。
  • 評論：播放頁的動畫名稱下方有「我的評論」面板。
  • 卡片標章：看過的動畫會顯示「看到第 N 集」，看完最新一集則顯示「✓ 看完」。
  • 手動標記看完：動畫瘋播放頁的評論面板有「標記看完／取消看完」；管理頁的作品頁可標記看完、標記沒看完或改回自動判斷。手動標記會蓋過自動判斷，標記看完的時間會出現在觀看紀錄裡（在觀看紀錄按「取消標記」即可取消）。
  • 收藏與分群（管理頁）：作品卡片與作品頁的愛心可收藏；「分群」頁可新增、改名、刪除分群，作品頁勾選要加入的分群（一部作品可屬於多個分群）。
  • 作品的評分：取最新一則有給星的評論。
  • 管理頁：作品列表可依來源、分群、評分（N 星以上、未評分）篩選，並依最後觀看、名稱、評分、建檔時間排序。點 extension 圖示 →「開啟管理頁」，或直接開啟 http://127.0.0.1:17890。
  • popup 設定：可暫時顯示已隱藏的動畫，或把隱藏方式改成完全移除。

同步動畫瘋的觀看紀錄（含手機、其他電腦看的）

  • 自動：瀏覽器開著、server 有啟動、動畫瘋保持登入時，背景每 6 小時同步一次。可在 popup 關閉「每 6 小時自動同步」。
  • 開啟觀看紀錄頁（viewList.php）時也會同步，結果顯示在頁面上方。
  • 完整同步：popup 的「立即完整同步」或觀看紀錄頁的「完整同步」會重新讀取全部紀錄（約一年內），第一次使用時建議執行一次。
  • 重複同步不會產生重複資料；同一集重看會保留每一次。判斷方式見 可行性評估 的 M6。

Netflix

  • 卡片：首頁、類別頁的卡片同樣有「隱藏」按鈕與觀看標章（影集、電影都適用）。
  • 觀看紀錄：在 Netflix 播放時自動記錄，與動畫瘋相同。
  • 同步：開啟 Netflix 的「觀影動態」頁（popup 有連結）時，會同步各作品的觀看紀錄，包含其他裝置看的。要同步更早的作品，先按頁面上的「顯示更多」，再按「再次同步」。
  • 評論請在管理頁的作品頁面撰寫。

合併同一部作品

動畫瘋與 Netflix 上的同一部作品是分開的兩筆資料，不會自動合併。管理頁的「合併」頁會列出名稱相似的作品，可以選擇「合併」（並決定保留哪一邊的名稱）或「不是同一部」（之後不再列出）。沒列出的作品，可在作品頁面的「合併其他作品」搜尋後合併。合併後無法復原。

相關作品（續作、前傳）

管理頁的作品頁有「相關作品」區塊，兩部作品互相列出，但每一季仍是獨立的作品（隱藏、進度、評論各自分開）。

  • 動畫瘋：打開播放頁時會記下頁面上的「相關動畫」；已建檔的作品由 server 在背景補抓（啟動時與之後每小時檢查一次，每部間隔 1.5 秒）。還沒建檔的相關動畫只列名稱，點了開動畫瘋，不會在作品列表多出一筆。
  • 手動：在作品頁搜尋其他作品按「加入關聯」，例如把動畫瘋的作品與 Netflix 的作品關聯起來。按「移除」可取消；移除後即使動畫瘋仍列出，也不會再加回來。

Server 沒開時

extension 圖示會出現紅色「!」，動畫瘋頁面也會跳出提示。期間的觀看紀錄、隱藏與評論會暫存在瀏覽器中，server 啟動後（最慢 30 秒內）會自動補送。

3. 資料

路徑內容
data/app.dbSQLite 資料庫（動畫、集數、觀看紀錄、評論）
data/covers/封面圖片，檔名為本機動畫 ID
  • data/ 已加入 .gitignore，不會進 git。
  • 備份：先停止 server，再複製整個 data/ 資料夾。
  • 可用環境變數 AGM_DATA_DIR 改變資料目錄，AGM_PORT 改變連接埠（改了要同步到 popup 的「進階設定」）。

4. 開發

npm run dev:server     # server（檔案變更自動重啟）
npm run dev:web        # 管理頁：http://localhost:5173，API 會 proxy 到 server
npm run dev:ext        # extension：載入 apps/extension/.output/chrome-mv3-dev
npm test               # 全部測試
npm run typecheck

專案結構

目錄說明
packages/sharedAPI 型別與 zod schema，server 與前端共用
apps/serverHono + node:sqlite；schema 遷移在 src/db.ts（只能往後加）
apps/web管理頁（Vite + React）
apps/extensionWXT + React。src/bahamut/、src/netflix/ 是各網站的選擇器與 API 解析，網站改版時先看這裡

網站改版時

  1. 播放頁解析失敗時，content script 會在 console 印出「無法解析播放頁」。
  2. 對照 頁面結構調查，修改 src/bahamut/parse.ts。
  3. 更新 apps/extension/test/fixtures/ 的頁面片段並跑測試。
